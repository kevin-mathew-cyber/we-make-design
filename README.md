# WM Designs

An independent creative and technology studio website built with Next.js App Router, TypeScript, Tailwind CSS and Framer Motion.

## Start locally

```bash
npm install
npm run dev
```

The site runs at `http://localhost:3000`.

## Project checks

```bash
npm run typecheck
npm run build
```

The contact form validates the required fields and prepares a `mailto:` draft for the visitor. Connect a studio inbox or form endpoint to receive enquiries directly.
